# 🔐 Authentication API

A secure backend authentication system built using **Node.js, Express, MongoDB, and JWT**.

---

## 🚀 Features

* ✅ User Registration
* ✅ User Login
* ✅ JWT Authentication
* ✅ Cookie-based Authentication
* ✅ Protected Routes
* ✅ Password Hashing (bcrypt)

---

## 🛠️ Tech Stack

* Node.js
* Express.js
* MongoDB (Mongoose)
* JSON Web Token (JWT)
* bcrypt
* cookie-parser

---


## 🔐 Authentication Flow

1. User registers or logs in
2. Server generates JWT token
3. Token is stored in cookies
4. Protected routes verify token using middleware
